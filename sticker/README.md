# ☕ Coffee Buddy sticker

A cute little coffee cup that floats on top of every window — it blinks, its steam wiggles, and it bobs gently.

## Run it
1. Install Python 3 from python.org (on Windows, tick **"Add Python to PATH"**).
2. Windows: double-click `run_sticker.bat`. Mac/Linux: `python3 sticker.py`.

## Controls
- **Drag** to move it
- **Double-click** → it waves and pops hearts ♥
- **Right-click** → change size, toggle bobbing, or quit

## Start automatically with Windows
Press `Win + R`, type `shell:startup`, and put a shortcut to `run_sticker.bat` in that folder.

## Games
It stays on top of normal apps and games running in **Windowed** or **Borderless / Windowed Fullscreen** mode.
Games in **exclusive Fullscreen** take over the whole screen, so no overlay can appear there. Switch the game's display mode to Borderless to keep the sticker visible.
